# Poems - The Song of Souls

A personal blog article page built as part of **The Odin Project** Foundations curriculum to practice HTML boilerplate structure, headings, paragraphs, line breaks, and inline text formatting.

## Overview

This project presents a short reflective essay on poetry—mentioning renowned Indian poets, a personal family note, and an original poem titled *"What to Learn?"*. It applies core HTML text elements including headings (`<h1>`, `<h3>`), paragraphs (`<p>`), line breaks (`<br>`), semantic bold (`<strong>`), and italic (`<em>`) tags.

## Built With

- **HTML5**

## Getting Started

To view the project locally:

1. Clone the repository:
   ```bash
   git clone [https://github.com/Pratishtha103/blog-article.git](https://github.com/Pratishtha103/blog-article.git)
   ```
2. Navigate into the project directory:
   ```bash
   cd blog-article
   ```
3. Open `index.html` directly in your browser (or run it using VS Code's Live Server extension).
